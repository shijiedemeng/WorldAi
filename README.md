# World

[中文说明](README_CN.md) | [English README](README_EN.md)

⭐ World

World 是一个分布式 AI 编排系统，允许单个开发者跨多台机器统一调度和协同本地编码智能体。

它能够实现：

* 在本地多环境中进行多智能体任务编排与协作
* 从需求 → 任务 → 实现的结构化工作流执行
* 将项目规范与文档动态注入到智能体执行上下文中
* 将执行结果持续反馈并沉淀为项目知识库
* 对分布在不同机器上的 AI 编程工作单元进行统一控制与管理

一句话总结：
一个开发者，多台机器，统一协同的 AI 执行系统。

⭐ World

World is a distributed AI orchestration system that allows a single developer to coordinate multiple local coding agents across different machines.
It enables:

* Multi-agent task orchestration across local environments
* Structured workflow execution from requirement → task → implementation
* Injection of project-specific standards and documentation into agents
* Continuous feedback loop from execution results to knowledge base
* Centralized control of distributed AI coding workers

In short:
One developer, multiple machines, coordinated AI execution system.
