# World

World is an AI orchestration platform for software project collaboration. It connects a Vue frontend, a Spring Boot backend, a local Python execution client, and a vector knowledge service to manage projects, agents, requirement decomposition, workflow execution, defect analysis, AI audit logs, and reusable project knowledge. It is designed for teams that want to coordinate local coding agents, inject project-specific standards and documentation into agent sessions, track execution results, and build a searchable knowledge base from real delivery feedback.
