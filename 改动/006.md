开发链路提示这个任务已经完成了，但是子模块列表显示的是PENDING
ai修复情况:
  已处理。

  1. 后端增加“链路状态驱动子任务状态”的自动同步
     - 开发链路创建后，会根据该子任务下的链路状态自动计算子任务状态
     - 开发链路更新进度后，也会自动重新计算所属子任务状态

  2. 当前同步规则
     - 如果子任务下所有链路都是 `TODO`，子任务保持 `PENDING`
     - 如果任意链路为 `BLOCKED`，子任务变为 `BLOCKED`
     - 如果所有链路都是 `DONE` 或 `SKIPPED`，子任务变为 `DONE`
     - 如果存在 `DOING`，子任务变为 `IN_PROGRESS`
     - 如果已经有部分链路完成，但未全部完成，子任务也会变为 `IN_PROGRESS`

  3. 修复后的目标效果
     - 不再出现“开发链路已经 `DONE`，但子模块列表仍然显示 `PENDING`”的问题
     - 子任务状态会跟随链路执行状态自动变化

  4. 技能文档补充
     - 已补充 skill 说明：链路回写完成后，必须确认所属子任务状态是否同步
     - 目标是避免 AI 只回写链路，不关注子任务状态

  5. 验证情况
     - 前端构建通过：`npm run build`
     - skill 脚本检查通过：`python3 -m compileall skills/ai-api-agent-integration/scripts`
