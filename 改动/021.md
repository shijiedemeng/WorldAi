   设计一个基于 Java + MySQL 的 Markdown 文档库模块，支持 Markdown 文档的树形层级结构管理与基础引用关系管理。系统通过 parent_id 实现文档的上下级组织结构，使文档形成可导航的知识树，同时支持 refs 字段实现文档间的弱关联引用关系。模块仅负责文档的存储、层级关系维护、基础检索及引用关系管理，不包含 AI、向量化或语义分析能力。所有 Markdown 文件采用 YAML FrontMatter 规范，必须包含 id、title、type、status 等基础字段，并支持 parent_id 构建层级结构。系统提供基础 REST API，包括文档增删改查、子树查询、路径查询及引用关系查询能力。
   文件需要支持下载功能
