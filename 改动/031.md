需求改动:
   新增功能(引入向量库 Milvus 直接在milvusClient 创建pymilvus即可) - 项目储备库
   以项目为单位，创建向量库，存储项目储备知识
   类型两种，一种是项目常见问题 第二种流程说明
   简单描述，详细内容
   首先这个一个向量库，新增和修改你都需要把内容选择ai api，然后生成对于向量和向量文件存储起来，然后对外提供mcp协议给其他ai做查询工具，提供api给java后端操作
   然后新增的数据有两种，第一种是直接新增，然后通过ai api生成向量，然后从向量库里找到最符合给页面选择，如果选择，那么把内容和新增的内容给ai api整合，内容展示做页面上，等待确定，确定之后，重新生成向量更新向量库，也就有一个确定的步骤
   另外一种新增就是通过需求详情，点击新增向量，把回执统计起来，给ai 整理，然后人工确定，确定之后生成向量存储到向量库里，和上面的步骤一样，但是需求详情如果已经有保存成功的向量内容，可以点查看，直接查看内容，但是不能在点新增向量了
   ai的工作第一个就是整理内容，第二个就是生成向量，第一个可以按钮点击多次，但是生成向量，只能有明确的修改才会亮起，而且整理也可以选择对应文档库标准，允许多选
ai修复情况:
   已新增“项目储备库”后端模块:
   1. 新增 project_knowledge_item 表，按项目存储储备知识，类型支持“项目常见问题”和“流程说明”。
   2. 新增项目储备库 API: 列表、详情、新增、修改、删除、AI整理、确认入库、相似查询、需求回执转储备知识。
   3. 新增向量状态和确认流程: 草稿/已整理/已确认，向量状态为待生成/已入库/需更新/失败；内容修改后会标记 vectorDirtyFlag，只有有明确修改时才需要重新确认入库。
   4. AI整理使用已配置的 AI 模型，请求 responses 接口；生成向量使用同一套 AI 配置的 embeddings 接口。
   5. AI 响应读取改为 byte[] 后再解析 JSON，避免 application/json 响应提取 String 时失败。

   已新增 Milvus Lite 本地向量服务:
   1. 在 milvusClient 下新增 pymilvus 服务，默认使用 Milvus Lite 文件库 state/milvus-lite/ai_api.db，不依赖 Docker 容器。
   2. 提供 /health、/vectors/upsert、/vectors/search、/vectors/delete 给 Java 后端调用。
   3. application.yml 新增 ai.knowledge.vector-base-url 等连接配置，Java 只对接向量服务 URL，不控制 Milvus Lite 的 DB 文件路径，也不配置 collection 前缀或隔离策略。
   4. 向量库不走页面配置。查询、写入和删除都显式携带项目列表里的 projectCode 作为业务隔离参数，milvusClient 内部按 projectCode 隔离数据，避免查到其他项目。Milvus Lite 的 DB 文件路径由 milvusClient 服务自身启动参数 --uri 或 MILVUS_URI 控制。

   已新增 MCP 查询入口:
   1. 新增 /api/mcp/project-knowledge/tools，暴露 project_knowledge_search 工具定义。
   2. 新增 /api/mcp/project-knowledge/search，供其他 AI/Agent 按 projectCode、query、knowledgeType 查询项目储备知识。
   3. milvusClient 新增 MCP SSE 兼容入口 /mcp/sse 和 /mcp/messages，支持 initialize、ping、tools/list、tools/call，并提供 milvus_vector_search、milvus_vector_upsert、milvus_vector_delete 三个工具。

   已新增前端页面和入口:
   1. 菜单“项目协作”下新增“项目储备库”页面，支持项目、类型、状态、向量状态、关键词筛选。
   2. 项目列表增加“储备库”快捷入口，可带 projectCode 打开对应项目知识。
   3. 储备库页面支持直接新增、编辑、AI整理、查找相似、确认入库和删除。
   4. 需求详情新增“新增向量/查看向量”入口，可从当前需求说明和可提取执行回执创建储备知识草稿；若已经有确认成功的向量知识，只允许查看，不允许重复新增。
   5. 需求详情新增向量草稿后，可以选择 AI 配置、embedding 配置和多个文档库标准，AI整理可反复执行，确认入库时生成向量并写入 Milvus Lite。
