# 缺陷修复 / UI体系重构

## 严重问题
当前UI体系不符合企业级后台规范，存在布局松散、层级不清晰、组件风格不统一的问题。

---

## 需求改动

### 1. UI体系调整
使用Element Plus 重构后台UI体系：

---

### 2. 设计规范（必须严格遵守）

- 企业级 SaaS 风格（参考 Ant Design Pro / 阿里云控制台）
- 卡片化布局（所有模块必须使用 el-card 包裹）
- 清晰视觉层级（Header / Filter / Table / Pagination）
- 统一间距系统（16px / 24px）
- 禁止密集堆叠式UI结构
- 禁止裸组件直接排列（必须有容器结构）

---

### 3. 页面结构标准（必须遵守）

- 顶部：页面标题 + 操作按钮区
- 中部：筛选区域（el-form）
- 主体：数据表格（el-table）
- 底部：分页（el-pagination）

---

### 4. 视觉要求

- 卡片分区明显
- 留白充足
- 层级清晰
- 表格对齐规范
- 不允许默认灰色堆叠风

---

## AI修复目标

- 统一UI风格
- 提升页面层级结构
- 提升整体视觉专业度
- 符合企业级后台标准

## AI修复情况

1. 已建立统一后台 UI 基础规范：
   - 调整全局后台背景、卡片、表格、页面标题、工具栏、筛选栏、分页栏样式。
   - 新增统一结构类：`admin-page`、`filter-card`、`table-card`、`content-card`、`filter-form`、`table-toolbar`、`pagination-bar`、`form-shell`、`form-actions`。
   - 页面间距统一为 16px / 24px，卡片边框、阴影、表头层级按企业级 SaaS 后台风格统一。

2. 已重构主要列表页为标准结构：
   - 项目列表：顶部标题 + 操作按钮、筛选卡、表格卡、分页。
   - 需求列表：顶部标题 + 操作按钮、筛选卡、表格卡、分页。
   - Agent 列表：顶部标题 + 操作按钮、筛选卡、表格卡、分页。
   - 缺陷同步：顶部标题 + 操作按钮、筛选卡、表格卡、分页；保留平台详情抽屉和后续分析流程。

3. 已重构主要表单页为卡片化布局：
   - 新建/编辑项目：表单放入 `el-card`，操作按钮统一放入表单动作区。
   - 新建/编辑 Agent：表单放入 `el-card`，选择器宽度与表单容器统一。
   - 新建/编辑需求：表单放入 `el-card`，使用 `el-row` / `el-col` 分列，减少密集堆叠。

4. 已补齐常用数据页容器结构：
   - Agent 任务页改为表格卡片结构。
   - 仪表盘改为内容卡片 + 指标块结构，避免默认灰色堆叠式卡片。

5. 验证情况：
   - 前端 `npm run build` 已通过。
   - 后端未涉及本次 UI 改动。
